# SOURCES — statement registry

Every factual statement in the atlas is traceable to a source listed here. This file is the human-readable counterpart to `data/sources.json`; the bibliography page is generated from the same records.

**Access date for all online sources: 2026-11-15.** All translations from Russian are working translations made for this edition.

Evidence levels: **D** = documented, **I** = interpretation, **R** = reconstruction. The levels are also marked on the plates.

### What is *not* a source

## 3. Claims deliberately not made

- That the third/ninth/fortieth-day scheme is pre-Christian in origin.
- That any single grave-cross type has a bounded regional distribution.
- That the mirror custom is ancient.
- That “Russian” custom and East Slavic custom are the same thing.
- That the number of dead at Piskaryovskoye or Vagankovo can be stated precisely.
- That the post-Soviet digital memorial has a known scale or chronology.
- Any quotation attributed to a named scholar that was not verified in a listed source.
